# Headliner Draft

A self-contained browser game for drafting a six-artist festival lineup.

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

1. Create a new GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Commit and push the files.
4. In GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select your main branch and the `/ (root)` folder.
7. Save.

GitHub will provide the public Pages URL after deployment.

## Files

- `index.html` — the complete game
- `.nojekyll` — tells GitHub Pages to serve the files as-is

The game is self-contained and does not require a build step or package manager.
